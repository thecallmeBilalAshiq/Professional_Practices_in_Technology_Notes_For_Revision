# 🚀 PPIT Master Revision Hub

![Build Status](https://img.shields.io/badge/Build-Success-success?style=for-the-badge)
![Tech Stack](https://img.shields.io/badge/Tech_Stack-HTML5_|_Tailwind_CSS_|_Three.js-blue?style=for-the-badge)
![Course](https://img.shields.io/badge/Course-Professional_Practices_in_IT-purple?style=for-the-badge)

A cutting-edge, interactive web platform designed specifically for quick, high-yield exam revision of the **Professional Practices in IT (PPIT)** course. This project unifies three extensive study modules (Mid 1, Mid 2, and Final) into a single, breathtaking 3D-animated environment. 

All content is translated into an easy-to-understand **Roman Urdu + English** format, optimized for rapid learning and exam preparation.

---

## ✨ Key Features

- 🌌 **3D Interactive Universe Background**: Powered by **Three.js** and **GSAP**, featuring a dynamic, mouse-reactive particle system.
- 🪟 **Glassmorphism UI**: A sleek, modern user interface built entirely with **Tailwind CSS**.
- 🛡️ **Sandboxed Architecture**: Uses an isolated iframe structure to seamlessly toggle between massive HTML modules without any CSS or variable clashing.
- 📚 **Comprehensive Course Coverage**: 
  - **Mid - 01**: Evolution of Profession, Ethics, Ethical Decision Making, SE & ACM Codes.
  - **Mid - 02**: IT Law, Intellectual Property Rights, Patents, Trademarks, Privacy, and IT Contracts.
  - **Final**: Computer Crimes, Forensics, Organizational Structures, Leadership, Management, and Conflict/Negotiation.
- 🧠 **Interactive Learning Tools**: Built-in click-to-flip flashcards and self-testing MCQs.
- 🖨️ **Print & Mobile Ready**: Fully responsive layouts that automatically strip heavy UI elements when printing to physical PDF study guides.

---

## 🛠️ Technologies Used

- **HTML5 & CSS3**
- **Tailwind CSS** (via CDN for rapid styling and layout constraints)
- **Vanilla JavaScript** - **Three.js** (WebGL 3D Rendering Engine)
- **GSAP** (GreenSock Animation Platform for fluid UI transitions)

---

## 🚀 Getting Started

Since this project is completely self-contained, no complex build tools or package managers are required.

1. **Clone or Download** the repository to your local machine.
2. **Ensure all files are combined** (the `index.html` should contain the embedded module data if using the master shell).
3. **Double-click `index.html`** to open it in your preferred modern web browser (Chrome, Edge, Firefox, Brave).
4. **Navigate** using the top tab buttons to switch between the Mid 1, Mid 2, and Final exam modules.
